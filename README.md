# PLOTVERSE Android Starter

Начальный Android-проект PLOTVERSE с интерфейсом Obsidian на HTML/CSS/JavaScript внутри Android WebView.

## Сборка APK через GitHub Actions

1. Создайте отдельный пустой репозиторий GitHub с названием `PLOTVERSE`.
2. Загрузите содержимое этого архива в корень репозитория (не сам ZIP-файл).
3. Откройте вкладку **Actions** и разрешите запуск workflows, если GitHub попросит.
4. Запустите **Build PLOTVERSE APK** через **Run workflow** или сделайте push в ветку `main`.
5. Откройте успешный запуск и скачайте артефакт `PLOTVERSE-debug-apk`.

## Что сейчас работает

- Главная, каталог и поиск по демонстрационным произведениям.
- Карточка произведения и список глав.
- Демонстрационная читалка с изменением размера текста и темы.
- Кабинет автора и демонстрационная форма нового произведения.
- Раздел будущей интеграции с PLOTNEST.
- Нижняя навигация и графитово-чёрная тема Obsidian.

## Важно

Это стартовый UI-прототип. Авторизация, серверная база, реальная публикация, синхронизация между устройствами, модерация и интеграция с PLOTNEST ещё не реализованы. В приложении нет встроенных секретных API-ключей.
